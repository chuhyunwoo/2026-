# 🐍 Python MBTI 검사 프로그램

이 프로그램은 Python 콘솔 환경에서 간단한 질문을 통해 사용자의 성향을 분석하고 MBTI 유형과 해설을 제공하는 프로그램입니다.

---

## 📋 1. 프로그램 개요
* **프로그램 이름**: Python Console MBTI Tester
* **개발 환경**: Python 3.9 (Miniconda 가상환경), VS Code
* **주요 기능**:
  * 총 12개의 문항을 통한 E/I, S/N, T/F, J/P 지표 측정
  * 사용자의 응답에 따른 실시간 점수 누적 및 최종 MBTI 유형 계산
  * 16가지 성격 유형별 맞춤형 상세 해설 제공

---

## 🗂️ 2. 자료 구조
* **`scores` (점수 저장용 딕셔너리)**:
  * 8개의 지표(`E`, `I`, `S`, `N`, `T`, `F`, `J`, `P`)를 키(Key)로 하고, 각 지표별 선택 횟수를 값(Value)으로 저장하여 누적합니다.
* **`questions` (문항 리스트)**:
  * 각 문항이 딕셔너리 구조로 이루어져 있으며, 질문 내용(`q`)과 보기 A, B의 내용 및 각각 대응하는 성향 지표를 튜플 형태로 담고 있습니다.
* **`descriptions` (해설 딕셔너리)**:
  * 16가지 MBTI 유형별 특징과 설명을 키-값 쌍으로 매핑하여 최종 결과에 맞는 해설을 출력합니다.

---

## 📝 3. 문항 구성 (총 12문항)
각 성격 지표당 3문항씩 총 12문항이 공정하게 배정되어 있으며, 문항 수가 홀수가 아니므로 각 지표별 동점(무승부) 발생 없이 명확한 결과 도출이 가능합니다.

1. **E vs I (에너지 방향)**: 외향성 및 내향성 성향 분석 (3문항)
2. **S vs N (인식 방식)**: 감각적/현실적 vs 직관적/아이디어 지향 성향 분석 (3문항)
3. **T vs F (판단 방식)**: 사고 중심(논리) vs 감정 중심(공감) 성향 분석 (3문항)
4. **J vs P (생활 양식)**: 계획적/체계적 vs 즉흥적/자유분방 성향 분석 (3문항)
